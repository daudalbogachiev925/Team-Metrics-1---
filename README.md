# Team-Metrics-1---
Описание: метрики команды разработки: velocity, cycle time, DORA, code churn, bug rate, нагрузка.

Метрики команды 1С-разработки:
- DORA (deployment frequency, lead time, CFR, MTTR)
- Velocity, predictability
- Code churn, hotspots
- Bug rate, reopened, escape rate
- Load per developer, unbalanced load, estimation accuracy

## Запуск
```bash
pip install -r requirements.txt
streamlit run app.py
pytest -v
```
